# Seguridad

- Los originales son de solo lectura y se identifican por SHA-256.
- No se ejecuta contenido incrustado en imágenes o metadatos.
- Los nombres de archivo se normalizan y las rutas se validan.
- El servidor MCP local no envía archivos a Internet.
- Cualquier integración futura con APIs externas debe requerir consentimiento explícito.
- Los trabajos de fidelidad estricta prohíben generación completa del producto.
- No se guardan credenciales en el repositorio.
