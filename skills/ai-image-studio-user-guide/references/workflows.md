# Flujos cotidianos

## Fotografías ya realizadas

1. Inspeccionar archivos.
2. Clasificar categoría y destino.
3. Bloquear la especificación.
4. Preservar originales.
5. Procesar con herramientas realmente disponibles.
6. Ejecutar control de calidad.
7. Aprobar, exportar y empaquetar.

## Sesión todavía no realizada

1. Crear decisión universal.
2. Solicitar guía de captura.
3. Realizar toma de prueba.
4. Revisar histograma, enfoque y movimiento.
5. Completar la sesión.
6. Volver al flujo de archivos existentes.

## Producto para web

Puede generar dos familias separadas:

- Catálogo: fidelidad estricta y perfil de fondo del canal.
- Ambiente: derivado creativo independiente. Requiere descripción, referencia o autorización para recomendar escenarios.

## Personas y eventos

El fondo se trata según la intención de la imagen. No se aplican automáticamente reglas de ecommerce ni fondo blanco.
