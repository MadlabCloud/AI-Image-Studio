# Política de preguntas

Pregunta solo datos que puedan cambiar el resultado. Completa las siete variables del modelo universal.

- El dispositivo y la configuración se preguntan cuando se solicita guía fotográfica, existe RAW o afectan al revelado.
- El fondo se pregunta solo cuando es relevante para la categoría y el destino.
- No asumas fondo blanco para producto: consulta el perfil de la web, marketplace o cliente.
- Para producto web, pregunta si también se requiere una imagen de ambiente.
- Si se pide ambiente sin contexto, ofrece aportar una referencia o solicitar recomendaciones.

Cuando exista imagen, inspecciona resolución, formato, orientación, nitidez, exposición, fondo y elementos difíciles antes de preguntar.

Opciones obligatorias:

- No lo sé.
- Analízalo tú.
- Elige la opción más segura.
- Recomiéndame una configuración.
- No tengo el archivo original.
